# PlanSight web UI

Vite + React + TypeScript front end for PlanSight (scaffolded with `create-cloudinary-react`).
See the [root README](../README.md) for the project, architecture and results.

```powershell
npm install
npm run build   # output is served by the FastAPI app (plansight/api/app.py)
npm run dev     # dev server; expects the API on http://localhost:8000 (see vite.config.ts)
```
